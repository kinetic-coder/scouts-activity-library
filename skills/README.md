# Meeting planning skills

These version-controlled Markdown instructions define how to fill out each section of a Scouts meeting plan. Read `skills/README.md`, `templates/meeting-plan.md`, and all seven section skills before drafting or changing a plan. Follow the latest committed version, not remembered conventions. Record exceptions and propose changes by pull request. Do not put young people's personal information in plans.

Skills: 01 meeting details; 02 objectives; 03 equipment; 04 running order; 05 activities; 06 risk assessment; 07 badge mapping and review.

Each skill defines required fields, checks, and an example. The meeting leader must validate factual details, badge criteria and safety decisions before use.

Additional authoring skill: `08-create-reusable-activity.md` defines how to create independent activity documents that meeting plans can reference.
