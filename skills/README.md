# Meeting planning skills

These version-controlled Markdown instructions define how to fill out each section of a Scouts meeting plan. Read `skills/README.md`, `templates/meeting-plan.md`, and the section skills before drafting or changing a plan. Follow the latest committed version, not remembered conventions. Record exceptions and propose changes by pull request. Do not put young people's personal information in plans.

Skills: 01 meeting details; 02 objectives; 03 equipment; 09 artifacts; 04 running order; 05 activities; 06 risk assessment; 07 badge mapping and review.

Each skill defines required fields, checks, and an example. The meeting leader must validate factual details, badge criteria and safety decisions before use. Every plan must include an `# Artifacts` section with working Markdown links to session files (or `None`).

Additional authoring skills: `08-create-reusable-activity.md` for independent activity documents; `09-artifacts.md` for the required Artifacts section and session `assets/` links.

Visual output skill: `10-visual-formatting-and-accessibility.md` for session pages, presentations, answer sheets, printables and generated web output. It applies whenever an AI creates or changes a visual artifact.
