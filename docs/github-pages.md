# Browse sessions on GitHub Pages

This site is built from Markdown on every pull request (download the `scout-pages-preview` Actions artifact) and deployed when changes reach `master`.

In GitHub repository Settings → Pages, set **Build and deployment** to **GitHub Actions**. GitHub Pages must be enabled and available for this repository. The public site will then normally be at `https://kinetic-coder.github.io/scouts-activity-library/`; confirm the actual URL from the Pages deployment before sharing.

Navigate **section → session → activity → presentation**. Presentations open in a new tab; use the browser's fullscreen mode (F11 on most Windows browsers) on a connected projector. Slide decks remain standalone HTML under `assets/` and can also be downloaded for offline use.

The site contains no authentication. **Do not commit or publish children's names, contact details, attendance, safeguarding details, or private leader information.** Review content before merging.
